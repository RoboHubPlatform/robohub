Applications

Applications declare an application block in their manifest. A keeper-hosted application is built and run on its own port; the keeper can start and stop it, and can add it to the left menu.

Install an application

Clone an application from a git URL, or register one that already lives on this machine. A registered application is not moved or copied; its folder stays where it is.

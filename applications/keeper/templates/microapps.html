Modules

Reusable modules with a backend, pages and storage of their own. They are installed under modules/ and listed in modules/registry.yml. A module has no port of its own: the application that hosts it includes it, and Open follows the host's address and the module's route.

Install a module

Clone a module from a git URL, or install one that already exists on this machine. A module is a Rho application whose manifest carries a module_app block.

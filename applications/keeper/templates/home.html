RoboHub Keeper

A local dashboard for the RoboHub ecosystem.

The ecosystem is a set of repositories, each versioned and built apart. The keeper shows what is installed, what runs, and which reusable pieces an application carries.

  • Registry — the RoboHub repositories and what is installed
  • Applications — the applications the keeper hosts, with open, start, stop and menu entries
  • App modules — reusable application modules, included by a host application rather than running on a port of their own
  • Plugins — alert channels and other plugins an application loads
  • Docs — the documentation built from the ecosystem

Registry is the repositories the orchestrator publishes and installs. Modules are the full-stack pieces an application includes — the inventory tracker in the aquarium, for example. A module has no process or port; its host application serves its routes.
